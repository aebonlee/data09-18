## 실행 방법

**온라인에서 바로 쓰기: https://aebonlee.github.io/data09-18/**

내 PC에서 쓰려면 설치 없이 아래 두 방법 중 하나로 엽니다.

1. **파일로 바로 열기** — 이 폴더의 `index.html` 을 더블클릭해 크롬·엣지로 엽니다. 인터넷이 없어도 동작합니다(엑셀 라이브러리도 `vendor/` 에 들어 있습니다).
2. **간이 서버로 열기** — 폴더에서 `python3 -m http.server 8000` 을 실행하고 브라우저에서 `http://localhost:8000` 을 엽니다.

처음 열면 자료가 비어 있습니다. **「예시 데이터 불러오기」** 를 누르면 시연용 가상 데이터(기준일 2026-09-28)가 들어가고, 화면 위에 「예시 데이터」 안내 띠가 표시됩니다.

사용 순서: **수주 취합**(포털 납품예정·누적결품·직송, 밥캣 xls, 발주서 엑셀·PDF, 선적계획·창고별재고현황을 한꺼번에 넣기 → 품번 매핑표 넣기(천일품번, 충돌은 그 자리에서 고르기) → 품번별 납품처 적기(한 번 적으면 기억) → 「이 수주로 선적계획 계산」·「업로드 양식으로 내보내기」(기존 17열 그대로) → **완제품정보** 넣기(천일품번 마스터 — **매입단가 = 「발주단가(원화)」 그대로**, 고객사 · 단종/생산금지. 완제품정보에 없는 품번만 원화로 직접 적기) → **월별 수주 vs 매입**(납기월(확정)별 수주금액·발주금액·비중(발주÷수주 %), 보조로 차액·차익률, **고객사별 비교** — 고객사 = 완제품정보, 없으면 빈칸)) 또는 자료 가져오기(수주현황·재고현황·선적예정 파일을 넣고 열 매핑) → 설정(기준일·안전재고·판정 기준·입고예정일 규칙·휴일) → 대시보드 / 과부족 현황 / 일자별 예상재고 → 선적계획(수정 가능) → AI 분석(질문문 복사·답 붙여넣기) → 공유·내보내기(Excel).

- 불러온 자료와 계산 결과는 **이 브라우저(localStorage)에만** 저장되며 외부로 전송되지 않습니다. 보관·이동은 「자료 가져오기」의 통합 데이터 파일(시트 3개)로 합니다.
- 예시 파일: `samples/예시데이터_수주현황.xlsx`·`예시데이터_재고현황.xlsx`·`예시데이터_선적예정.xlsx`(각 CSV 포함)와 `예시데이터_통합데이터.xlsx`. 모두 가상 데이터입니다.
- 수주 취합 예시 파일: `samples/수주취합/` 25개(포털 xlsx 12, 밥캣 xls 3, 발주서 xlsx 6·PDF 1, 선적계획·창고별재고현황, 판별 안 되는 파일 1). 모두 가상 데이터이고, 수주 취합 화면의 「예시 파일로 해 보기」로도 같은 결과를 봅니다.
- 품번 매핑표·업로드 양식·매입단가표·품번별 납품처 예시: `samples/품번매핑_업로드양식/` — 매핑표(시트 「건기엔진품목코드」「밥캣품목코드」, 열 고객사 | 천일품번) xlsx·CSV, 업로드 양식(시트 「웹자료올리기」 머리행 17열), 매입단가표(열 품목코드 | 품목명 | 생산처 | 매입단가), 품번별 납품처표(열 품목코드 | … | 납품처 코드 | 납품처명 | 담당자). 품번·단가·코드는 모두 가상입니다. 실제 매핑표·매입단가표·납품처·직접 적은 값은 이 브라우저에만 저장되고 리포에는 없습니다.
- 완제품정보 예시: `samples/예시데이터_완제품정보.xlsx` — 받은 파일과 같은 모양(3행 머리 · B열부터 · 빈칸은 0, 발주단가(원화) = 발주단가 × 230), 가상 품번 · 가상 고객사. 화면의 「예시 완제품정보로 해 보기」와 같은 값입니다. 실제 완제품정보는 이 브라우저에만 저장되고 리포에는 없습니다.
- 환율 예시: `samples/환율/` — `환율기준_양식.xlsx`(빈 「환율기준」 시트 + 「예시」 · 「안내」), `환율기준_서울외국환중개_복사형식_예시.csv`(서울외국환중개 월평균 화면을 복사한 모양), `매입단가표_통화칸_예시.xlsx`(「통화」 칸이 있는 매입단가표, 가상 품번·가상 단가). 예시의 환율 값은 서울외국환중개 실제 월평균입니다.
- 환율 자동 값(참고): `data/rates.json` · `data/rates.js` — 서울외국환중개 월평균 매매기준율(CNY 칸 = 위안(CNH), USD, JPY 100엔당, EUR) 최근 24개월. **2026-09-30(기획서 11.17)부터 매입단가에는 쓰지 않아 매일 받기(Actions 예약)를 껐습니다.** 필요하면 Actions 화면에서 `.github/workflows/rates.yml` 을 손으로 실행하거나 `node scripts/fetch-rates.mjs` 를 실행합니다(의존성 없음, Node 18 이상).
- 로직 테스트: `node test/logic.test.mjs` (의존성 없음)
- 예시 파일 다시 만들기: `node scripts/make-samples.js` · 수주 취합 예시: `node scripts/make-intake-samples.js` · 매핑표·업로드 양식·매입단가표·납품처 예시: `node scripts/make-mapping-samples.js` · 환율 · 완제품정보 예시: `node scripts/make-fx-samples.js`

## 1단계 구현 범위

기획서 5.3 기능 목록 기준입니다. 완료 = 이번 1단계 웹 도구에 들어감, 다음 단계 = 기획서 8장 2·3단계.

| 기능 (기획서 5장) | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 수주 자동 취합 (기획서 11장, 2026-09-29) | 완료 | 여러 파일 한꺼번에 넣기, 파일 이름으로 종류 판별(납품예정·누적결품·직송 × 건기·엔진·AM·CKD × 인천·군산·안산, 밥캣, 선적계획, 재고), 발주서는 머리행으로 양식 판별(목록형 3종·서식형·PDF), 엔진 결품 −2일·음수 → 양수·Mass PO 제외·결품 우선, 건기 누적결품 참고 제외, 밥캣 원납기 조임·겹침 제외, (CI) 삭제, 통합 수주 표 + ★확인 필요 + Excel, 「이 수주로 선적계획 계산」 |
| 수주 취합 확인 답변 반영 (기획서 11.9, 2026-09-30) | 완료 | 직송(인천건기·엔진·밥캣)도 납품예정과 같이 수주로, 밥캣 결품 납기 −2일, 엔진 결품·납품예정 겹침은 누적결품 기준, 발주서 최근 시트만, 재고 「완제품」 품번은 그대로(★확인 필요에서 뺌), 예전 저장 설정은 확정 칸만 새 기본값으로 |
| 품번 매핑표·ERP 업로드 양식 (기획서 11.10, 2026-09-30) | 완료 | 매핑표(xlsm·xlsx·csv, 건기·엔진 / 밥캣 두 묶음) 불러와 이 브라우저에만 저장, 통합 수주에 천일품번 열 → 재고·선적계획은 천일품번으로 맞춤, 「★확인 필요 — 매핑 없음」 개수, 같은 줄 반복·빈 칸 집계, 매핑 충돌 경고, 「업로드 양식으로 내보내기」(시트 「웹자료올리기」 17열 순서 그대로, 회사 양식 파일을 넣으면 그 순서), 납품처 설정표·고정값·일자·순번 설정. 채울 수 없는 열의 값은 확인 부탁 |
| 발주단가 (기획서 11.11, 2026-09-30) | 완료 | 통합 수주·Excel·수주현황·업로드 양식에 발주단가·금액(= 수량 × 단가)·단가 출처. 원본 단가 칸(포털·밥캣 발주단가, 발주서 단가·발주단가 ÷ 가격단위, PDF 단가) → 같은 고객사·품번의 다른 파일 단가(한 가지일 때만) → 직접입력 → 단가표. 없으면 「단가 없음」 N행·M품번 + 목록·Excel 시트. 업로드 양식에 단가 열이 없으면 「수량」 뒤에 「단가」를 더함(설정). 기준은 확인 부탁 |
| 두 번째 답변 반영 (기획서 11.12, 2026-09-30) | 완료 | 업로드 양식: 일자 = 등록일자(오늘) `20260930`, 순번 1, 2, 3, 품목코드(상단) = 품목코드, 매핑 없는 품번은 고객사 원품번 그대로(옛 저장 설정은 확정값으로). **품번별 납품처** 입력 표(기억·「위와 같게」·빈 품번만·Excel 왕복). **판매단가(고객 발주, 참고) / 매입단가(생산처 발주)** 분리 — 매입단가표(품목코드 → 매입단가·생산처)·직접입력, 업로드 단가 = 매입단가, 판매 − 매입 차이(선택). **매핑 충돌** 표(고객사 품번·천일품번 후보·매핑표 행 번호)에서 쓸 값 고르기·Excel |
| 세 번째 답변 반영 · 월별 수주 vs 매입 (기획서 11.13, 2026-09-30) | 완료 | 업로드는 **기존 17열 양식 그대로**(단가 열 더하기는 선택으로만 — 17열에 단가·금액 칸 없음), 매입단가·매입금액은 통합 수주 표·Excel·월별 화면에. 매입단가표는 **천일품번으로만** 찾음. 작업지시No.·BOM버전·추가문자형식1·창고·적요·하위반제품수·규격은 비움(확정). 새 메뉴 **「월별 수주 vs 매입」** — 납기월(기본)·발주월, 수주금액(수량 × 판매단가)·매입금액(수량 × 매입단가)·차액·차익률(두 단가가 모두 있는 줄끼리), 쪽마다 단가 없음 행 수, 고객사·구분별, 품목별 상위 N, Excel 시트 「월별 수주 vs 매입」, DB 뷰 `intake_monthly_summary` |
