# data09-18 · 생산관리 선적계획 자동화 시스템

수주·현재고·중국 선적예정을 넣으면 요일 규칙으로 한국 입고예정일을 계산해 일자별 예상재고·과부족·부족 품번을 뽑고 선적계획을 만들어 주는 도구

| 항목 | 내용 |
|---|---|
| 제출자 | 안제민 |
| 과정 | 현장 데이터 수집·디지털화 전문가과정 1차수 (2026) |
| 진행 단계 | 1단계 — 프로젝트 기획서 등록 (2026-09-28) |
| 다음 개발 | 수주·재고·선적예정 Excel을 가져와 입고예정일 규칙(월~수 선적 → 2일 후, 목~금 선적 → 다음 월요일)으로 일자별 예상재고·과부족·부족 품번을 계산하고 선적계획을 만들어 Excel로 내보내는 브라우저 도구 |
