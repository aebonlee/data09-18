## 실행 방법

**온라인에서 바로 쓰기: https://aebonlee.github.io/data09-18/**

내 PC에서 쓰려면 설치 없이 아래 두 방법 중 하나로 엽니다.

1. **파일로 바로 열기** — 이 폴더의 `index.html` 을 더블클릭해 크롬·엣지로 엽니다. 인터넷이 없어도 동작합니다(엑셀 라이브러리도 `vendor/` 에 들어 있습니다).
2. **간이 서버로 열기** — 폴더에서 `python3 -m http.server 8000` 을 실행하고 브라우저에서 `http://localhost:8000` 을 엽니다.

처음 열면 자료가 비어 있습니다. **「예시 데이터 불러오기」** 를 누르면 시연용 가상 데이터(기준일 2026-09-28)가 들어가고, 화면 위에 「예시 데이터」 안내 띠가 표시됩니다.

사용 순서: 자료 가져오기(수주현황·재고현황·선적예정 파일을 넣고 열 매핑) → 설정(기준일·안전재고·판정 기준·입고예정일 규칙·휴일) → 대시보드 / 과부족 현황 / 일자별 예상재고 → 선적계획(수정 가능) → AI 분석(질문문 복사·답 붙여넣기) → 공유·내보내기(Excel).

- 불러온 자료와 계산 결과는 **이 브라우저(localStorage)에만** 저장되며 외부로 전송되지 않습니다. 보관·이동은 「자료 가져오기」의 통합 데이터 파일(시트 3개)로 합니다.
- 예시 파일: `samples/예시데이터_수주현황.xlsx`·`예시데이터_재고현황.xlsx`·`예시데이터_선적예정.xlsx`(각 CSV 포함)와 `예시데이터_통합데이터.xlsx`. 모두 가상 데이터입니다.
- 로직 테스트: `node test/logic.test.mjs` (의존성 없음)
- 예시 파일 다시 만들기: `node scripts/make-samples.js`

## 1단계 구현 범위

기획서 5.3 기능 목록 기준입니다. 완료 = 이번 1단계 웹 도구에 들어감, 다음 단계 = 기획서 8장 2·3단계.

| 기능 (기획서 5장) | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 수주·재고·선적예정 Excel 가져오기 | 완료 | xlsx·xls·csv(UTF-8·EUC-KR), 시트 선택, 머리행 지정, **열 매핑 화면**(기획안 항목 이름·동의어 자동 매핑), 매핑 저장(같은 양식 파일 자동 적용), 읽을 수 없는 칸은 행 번호로 안내 |
| 품번 매칭 | 완료 | 세 자료를 품번으로 묶음, 재고현황에 없는 품번·수주 없는 품번·재고 행 합산 표시 |
| 입고예정일 자동 계산 | 완료 | 월~수 +2일, 목·금 다음 월요일(요일별 「+N일」 설정 가능), 토·일은 규칙 없음(파일 값이 있으면 사용, 없으면 제외·경고), 휴일 목록 → 다음 영업일, 파일 입고예정일과 다르면 표시 |
| 일자별 예상재고 | 완료 | 기준일 현재고에서 입고예정(+)·납기일 수주(−)를 날짜순으로 반영. 기준일 전 납기는 기준일에 뺌(가정) |
| 과부족 분석·상태 판정 | 완료 | 예상재고 = 현재고 + 입고예정수량 − 수주수량, 과부족수량 = 예상재고 − 안전재고(기획안 8장). 긴급·부족·주의·과잉·정상 색상 구분. 긴급 일수·과잉 비율은 설정값(가정) |
| 안전재고 기준 | 완료 | 재고현황의 안전재고 열(선택) 또는 기본 안전재고 설정 |
| 부족 품번 추출 | 완료 | 과부족 현황에서 상태 필터·검색, 긴급 → 부족 → 주의 순, 첫 부족일·부족수량 표시 |
| 선적계획 생성 | 완료 | 부족일마다 모자란 수량을 입고예정일 규칙 역산으로 가장 늦은 선적일에 배정, 입고 여유일 설정, 제때 입고 불가 표시, 선적일·수량 수정(입고일 재계산)·되돌리기 |
| AI 분석 (반자동) | 완료 | 부족·긴급·주의 품번 수치로 질문문 생성·복사(고객사 제외, 품명은 선택) → 「품번 \| 우선순위 \| 의견」 형식 답 붙여넣기 → 품번별 의견 표·내보내기 반영 |
| Dashboard | 완료 | 전체 품번 수·수주수량·현재고·입고예정수량·부족 품번 수·부족수량·금주 선적수량·긴급 선적 품번, 상태별 색상 막대, 주차별 선적계획(확정 예정·제안) |
| 공유용 Excel 출력 | 완료 | 과부족현황·선적계획·부족품번·일자별예상재고·입고예정계산 5개 시트, 선적계획 CSV, 담당자 안내문 초안 복사, 통합 데이터 파일 |
| 선적 단위 반영 | 다음 단계 | 박스·팔레트 단위 확인 후 2단계 |
| 최근 수주량 변화 반영 | 다음 단계 | 과거 수주 이력 확보 후 2단계 |
| 담당자 자동 공유 | 다음 단계 | 2단계(Make) — 지금은 Excel·안내문 복사 |
| 계획 대비 실적 | 다음 단계 | 3단계 |
| 생산계획·구매발주량 자동 산출 | 다음 단계 | 3단계(기획안 15장 확장 계획) |
