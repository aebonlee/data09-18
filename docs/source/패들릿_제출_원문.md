2. 추진 배경

현재 생산관리 업무에서는 수주현황, 재고현황, 중국 선적예정 데이터를 각각의 엑셀 파일로 관리하고 담당자가 데이터를 취합하여 품번별 과부족을 계산한 후 부족수량에 대한 선적계획을 수작업으로 수립하고 있다. 이 과정은 반복 작업이 많고 수주 및 선적 변동이 발생할 경우 신속한 대응이 어렵다.

이에 기존 생산관리 데이터를 표준화하고 AI 및 자동화 기술을 적용하여 ‘수주 → 재고 → 선적 → 입고 → 과부족 → 선적계획’의 전체 흐름을 데이터 기반으로 전환하고자 한다.

3. 프로젝트 추진 목적

AI를 활용한 부족 및 긴급 선적 예상정보 제공

생산관리 담당자의 반복 업무 및 오류 감소

4. 현행 업무 및 문제점

현행 업무 프로세스

수주현황 확인 → 재고현황 확인 → 중국 선적예정 확인 → 엑셀 데이터 취합 → 과부족 계산 → 부족품 확인 → 선적계획 작성

| 구분 | 현행 문제 |
|---|---|
| 데이터 관리 | 여러 엑셀 파일에 데이터 분산 |
| 데이터 취합 | 담당자가 수작업으로 자료 통합 |
| 과부족 계산 | 수식 및 자료 확인 과정에서 오류 가능 |
| 입고예정 | 중국 선적일을 기준으로 별도 계산 필요 |
| 부족품 확인 | 담당자가 전체 품번을 직접 확인 |
| 선적계획 | 담당자의 경험 및 판단에 의존 |
| 긴급 대응 | 수주 변동 시 즉각적인 재계산 필요 |

5. 개선 업무 프로세스

| 결과 | 판정 |

| 0 | 적정 |

9. AI 선적계획 자동화

AI는 납기일, 수주수량, 현재고, 입고예정수량, 부족수량, 최근 수주량 변화, 안전재고 및 기존 선적계획을 분석하여 부족 및 긴급 품목을 우선적으로 식별한다.

예시: “A001 품번은 10월 2일 기준 재고 부족이 예상됩니다. 현재고 및 입고예정량을 고려할 경우 300EA의 추가 선적이 필요합니다.”
