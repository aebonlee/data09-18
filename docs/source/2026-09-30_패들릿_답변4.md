# 2026-09-30 패들릿 답변 (4) — 11.13 「남은 확인 부탁」 1~3에 대한 답

- 작성: 수강생(제출자) 본인
- 반영: 기획서 11.14
- 인용(>)은 답변 원문, 번호는 11.13 「남은 확인 부탁」 번호입니다.

1. 같은 품목을 생산처 여러 곳에 다른 단가로 발주하나요? 어느 생산처 단가를 쓸까요?

> 현재 생산처 이원화로 진행되지만 향후(1개월이내) 품번별 생산처는 1곳으로 지정되기 때문에 현재기준 가장 위쪽단가로 해도 무방합니다

2. 월별 표의 차액을 「두 단가가 모두 있는 줄끼리」로 계산했습니다. 「수주금액 합계 − 매입금액 합계」가 필요한가요?

> 단가가 없더라도 총금액비교 ex) 10월 수주금액 ****원 10월 발주금액 ****원 수주금액 대비 발주금액 **%(비중)

3. 월별 기준은 납기월을 기본으로 했습니다. 발주월 기준이 더 맞나요?

> 납기월 기준으로 부탁드립니다

요지: ① 매입단가표의 가장 위쪽 단가를 쓴다(고르는 화면 불필요) ② 단가가 없는 줄이 있어도 월별 총금액(수주금액 · 발주금액)과 비중(발주 ÷ 수주 %)을 본다 ③ 납기월 기준.
